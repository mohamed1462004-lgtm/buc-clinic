# BUC Family Health Center Landing Page

Arabic RTL landing page built with React, Vite, Tailwind CSS, and lucide-react.

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Logo

The supplied banner logo was cropped into `public/buc-family-health-center-logo.jpg`.
For a sharper production result, replace it with the official transparent PNG/SVG logo if the clinic provides one.

## Notes before publishing

- Phone numbers are from the user-provided banner.
- Facebook link is the page link supplied by the user.
- Location is stated broadly as Badr City, Cairo based on BUC's public site.
- Service descriptions are based on BUC's published medical-clinic information; confirm current availability directly with the clinic.
- The inquiry form opens WhatsApp with a prefilled message and does not save data. It intentionally does not ask for medical details.
- Replace stock photography with clinic-approved real photos before production.
- Confirm whether the center wants these contact numbers, location wording, and current services published before going live.
